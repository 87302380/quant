# 收益优先候选的前向模拟准备

本轮选定NFIOptWeightedNoAdds，149笔、正常费用收益184.01%/5m权益回撤16.56%，双倍手续费收益175.92%/回撤17.18%。源码、币池及配置SHA256见results/nfi/return_search/source_manifest.json。候选配置只用于后续dry-run，初始状态stopped，未启动进程、未接交易账户。

基线24h和overheat_no_adds使用独立钱包保留对照；不要把同一笔本金分配给各策略后相加收益。首个前向观察时间必须晚于实际冻结/启动时间，历史回放不混作前向样本。至少12周且60个已平仓周期后再评价，取较晚达到的时点；期间只修复数据/执行故障，不重调阈值。

目标是扣费后收益率，同时记录含浮亏回撤、最大同向和总名义敞口、24h退出是否真实完成、信号族利润集中度、补仓/部分退出、模拟成交延迟和成本敏感性。资金费仍按用户要求排除，报告明确标注；dry-run也不能证明实盘盘口成交能力。

收益优先候选继续使用NFI原生退出与极宽兜底；24h期限不是亏损金额保证。若出现期限违规或行情中断，停止新增模拟入场并诊断，保留现有退出处理。任何实盘切换仍需另行执行，不在本轮离线研究范围内。
